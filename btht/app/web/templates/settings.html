Your names for the kinds of network segment — workstations, servers, DMZ, UAV. Each firewall interface gets assigned one of these. Not the pfSense interface names: lan is workstations on most enclaves and servers on at least one, so an interface called lan tells you nothing about what is on it. An interface whose segment is not in this list is shown to you for a decision rather than guessed at.
Optional. If your firewalls describe an interface as do_svrs, stripping do_ leaves svrs and the tool can propose the segment when you import a configuration. Leave it blank and you assign segments by hand.
